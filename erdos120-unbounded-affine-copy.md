# Erdős #120 — unbounded sets admit a positive-measure affine-copy avoider

Author: Jared Wilder. Public release: 2026-09-11.

## Theorem

Let `A⊂R` be unbounded. Then the positive-measure set

`E=[0,1]`

contains no nondegenerate affine copy `aA+b` with `a!=0`.

## Proof

Multiplication by a nonzero scalar and translation preserve unboundedness, so `aA+b` is unbounded. Every subset of `[0,1]` is bounded. Hence `aA+b` cannot be contained in `[0,1]`.

Thus all unbounded `A` fall to this elementary obstruction. The remaining substantive regime is bounded infinite sets.

# Erdős #1142 — multiplicative-order subgroup sieve

**Author:** Jared Wilder  
**Public routing:** 2026-09-11

Call `n` **Good** when every number `n-2^j` with `1<2^j<n` is prime.

## Theorem

Let `p` be an odd prime and let

\[
r=\operatorname{ord}_p(2).
\]

If

\[
n>p+2^r
\]

and `n` is Good, then either `p|n` or

\[
\boxed{n\bmod p\notin\langle2\rangle}.
\]

## Proof

Assume `p∤n` and `n mod p` lies in the subgroup generated by 2. Choose `1<=j<=r` with

\[
n\equiv2^j\pmod p;
\]

if the natural exponent is zero, use `j=r` since `2^r≡1 mod p`.

The threshold gives

\[
n-2^j\ge n-2^r>p>1.
\]

But `p|(n-2^j)`, so `n-2^j` is a multiple of `p` strictly larger than `p`, hence composite. This contradicts Goodness.

## Primitive-root corollary

If 2 is a primitive root modulo `p`, then the nonzero subgroup is all of `(Z/pZ)^*`, so beyond the same threshold

\[
\boxed{\text{Good}(n)\Longrightarrow p|n.}
\]

Using `p=3` and `p=5`, if `n>21` is Good then

\[
\boxed{15|n.}
\]

The strict threshold is load-bearing: `n=21,p=5` is the stored regression witness against an earlier overstrong boundary statement.

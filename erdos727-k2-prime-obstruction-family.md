# Erdős #727 — infinite exact obstruction family at `k=2`

**Author:** Jared Wilder  
**Public release:** 2026-09-11  
**Status:** exact infinite obstruction family; parent problem remains open

Erdős #727 asks, for fixed `k>=2`, whether

`(n+k)!^2 | (2n)!`

holds for infinitely many `n`.

## Theorem

For every prime `p>=7`, set

`n=2p-2` and `k=2`.

Then

`(n+2)!^2` does **not** divide `(2n)!`.

Equivalently,

`(2p)!^2 ∤ (4p-4)!`.

Thus the `k=2` search contains an infinite parametric obstruction family.

## Proof

Compare the `p`-adic valuations.

Because `p>=7`, we have `p^2>2p`, hence

`v_p((2p)!) = floor(2p/p) = 2`.

Therefore

`v_p((2p)!^2)=4`.

On the other hand `p^2>4p-4` and

`3p <= 4p-4 < 4p`,

so

`v_p((4p-4)!) = floor((4p-4)/p) = 3`.

The right-hand side therefore contains only three factors of `p`, while the proposed divisor contains four. Divisibility is impossible.

## Scope

This is a negative family, not a negative solution of the parent problem: infinitely many failures do not rule out infinitely many successes for `k=2`, and the question also ranges over arbitrary fixed `k>=2`.

Its value is structural: it replaces isolated finite failures by an exact infinite family generated by one valuation mismatch.

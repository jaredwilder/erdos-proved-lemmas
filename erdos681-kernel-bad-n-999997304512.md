# Erdős #681 — a kernel-checked bad integer near 10^12

**Author:** Jared Wilder  
**Recovered / published:** 2026-09-14  
**Status:** finite exact theorem; does not resolve the eventual parent problem

Let

\[
n=999,997,304,512.
\]

Then there is **no** positive integer `k` for which `n+k` is composite and

\[
k^2 < P^-(n+k),
\]

where `P^-(m)` is the least prime factor. Equivalently, this `n` is a genuine bad integer for Erdős Problem #681.

The exact formal statement checked in Lean is

```lean
¬ ∃ k, 0 < k ∧ ¬ Nat.Prime (999997304512 + k) ∧
    1 < 999997304512 + k ∧
    k ^ 2 < Nat.minFac (999997304512 + k)
```

## How the certificate closes every k

The proof has two parts.

1. **Large shifts.** For every `k >= 1001`, the fourth-root necessity fails:

   ```text
   999997304512 + k <= k^4.
   ```

   Hence no such `k` can satisfy `k^2 < minFac(n+k)` for a composite endpoint.

2. **The finite window.** For every `1 <= k <= 1000`, the certificate proves either:

   - `n+k` is prime; or
   - an explicit divisor `q` satisfies `2 <= q <= k^2` and `q | n+k`.

   The table contains 40 prime shifts (including `k=1`) and explicit small-divisor kills for every other shift. The prime endpoints are proved by Lucas/Pratt-style certificates inside Lean rather than by probabilistic primality testing.

The campaign's independent endpoint enumeration found, for the corresponding residual prime `p=n+1=999,997,304,513`, 499 odd residual shifts through 999: 39 prime endpoints and 460 small-divisor kills. The final theorem additionally handles all positive `k`, including even shifts and the endpoint `k=1`.

## What this means — and what it does not

This proves that any eventual threshold `N0` in a positive solution of Erdős #681 must satisfy

\[
N_0 > 999,997,304,512.
\]

It does **not** disprove the parent statement, because the parent asks only for all sufficiently large `n`.

The theorem is published because a finite bad value at this scale, with a replayable kernel certificate, is an exact mathematical result independent of the still-open asymptotic question.
